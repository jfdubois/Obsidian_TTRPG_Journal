# How to Create a Session

## Purpose

This guide explains how to create a session note and what happens when you create later sessions in the same campaign.

## Prerequisites

Before using this workflow:

- open the relevant `Campaign.md` note
- confirm that the `Add Session` action is available

## Create a Session

1. Open the relevant `Campaign.md` note.
2. Click `Add Session`.

The session note is created automatically. You do not need to name it manually.

## What Happens Next

After the workflow completes:

- a new session note is created in the current campaign
- the session number is assigned automatically
- the current date is added automatically
- the new session appears in the `Sessions` section of `Campaign.md`

The session note includes:

- `Session Summary`
- `Recap`
- `Logs`

## First Session Behavior

If this is the first session in the campaign:

- the note starts with an empty `Session Summary`
- the `Recap` section shows that there is no previous session

## Later Session Behavior

If at least one session already exists in the campaign:

- the new session receives the next session number automatically
- the `Recap` section links back to the previous session
- the previous session's `Session Summary` is copied into the new session's `Recap`

This helps the latest session start with the most recent summary already visible.

## Using the Session Note

Use the main sections this way:

- write the important outcome of the session in `Session Summary`
- use `Recap` to quickly review what happened previously
- use `Logs` to record events, discoveries, and notes during play

## Result

At the end of this process, you have a new session note ready for play, and later sessions automatically carry forward the previous session summary into the new recap.
