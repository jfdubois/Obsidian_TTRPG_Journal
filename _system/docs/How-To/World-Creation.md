# How to Create a World

## Purpose

This guide explains how to create a new world and its first campaign from the vault index.

## Prerequisites

Before using this workflow:

- open `Worlds/TTRPG Game Index.md`
- confirm that the `Create World` action is available
- decide the world name you want to use
- decide the name of the first campaign you want to create in that world

## Create a World

1. Open `Worlds/TTRPG Game Index.md`.
2. Click `Create World`.
3. Enter the world name.
4. Select the role for this world:
   - `player`
   - `dm`
5. Enter the initial campaign name.

The workflow creates the world structure and the first campaign in a single process.

## What Happens Next

After the workflow completes:

- a new `World.md` note is created for the world
- a new `Campaign.md` note is created for the first campaign
- the new campaign note opens automatically

## Using the World Note

Use `World.md` as the main note for world-level information. It includes:

- a `World Notes` section for setting information
- an `Actions` section with `Add Campaign`
- a `Campaigns` section that lists campaigns in the world
- a `World knowledge` section for world-level notes and references

## Result

At the end of this process, you have a new world ready to use and a first campaign ready to begin.
