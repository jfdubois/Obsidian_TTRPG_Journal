# How to Create a Campaign in an Existing World

## Purpose

This guide explains how to create a new campaign inside an existing world.

## Prerequisites

Before using this workflow:

- create the world first
- decide which world the campaign belongs to
- decide the campaign name
- prepare optional timeline notes if you want to add them during setup

## Create a Campaign from a World Note

Use this method when you are already inside the correct world.

1. Open the relevant `World.md` note.
2. Click `Add Campaign`.
3. Enter the campaign name.
4. Enter optional timeline notes.

The new campaign is created inside that world automatically.

## Create a Campaign from the Vault Index

Use this method when you want to choose the world during creation.

1. Open `Worlds/TTRPG Game Index.md`.
2. Click `Create Campaign`.
3. Select the world.
4. Enter the campaign name.
5. Enter optional timeline notes.

## What Happens Next

After the workflow completes:

- a new `Campaign.md` note is created for that campaign
- the new campaign note opens automatically
- the campaign appears in the `Campaigns` section of the related `World.md`

## Using the Campaign Note

Use `Campaign.md` as the main note for day-to-day campaign activity. It includes:

- a `Players` section
- an `Actions` section with `Add Session` and `Add Entity`
- a `Create Encounter` action when the world role is `dm`
- a `Sessions` section for session history
- a `Campaign knowledge` section for campaign notes and references

## Result

At the end of this process, you have a new campaign ready to use inside the selected world.
